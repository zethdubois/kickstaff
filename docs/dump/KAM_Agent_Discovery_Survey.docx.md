# **Instructions for the Interviewer**

* Walk through each section below with the interviewee. Not every section will apply to every role — skip sections that genuinely don't apply, but confirm that with the interviewee rather than assuming.

* For each function, capture how it's actually done today, not how it's supposed to be done — the gap between the two is often the most useful finding.

* Priority: "Must" means the business cannot operate without it on day one of cutover. "Nice" means it's valuable but could follow in a later update.

* Use the Pain Points column to capture anything that's slow, error-prone, duplicated across tools, or a workaround — this is where KAM Agent can improve on Appfolio, not just replicate it.

* Add rows for anything not already listed. The categories below are a starting point, not a ceiling.
